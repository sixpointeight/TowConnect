# Towing Company Website Design Guidelines

## Design Approach
**Reference-Based Approach**: Drawing inspiration from service industry leaders like Angie's List and local service businesses, emphasizing trust, reliability, and immediate accessibility.

## Core Design Elements

### Color Palette
**Primary Colors:**
- Deep Blue: 220 85% 25% (trust, reliability)
- Safety Orange: 25 95% 55% (emergency, visibility)
- Clean White: 0 0% 98%

**Dark Mode:**
- Charcoal: 220 15% 15%
- Muted Orange: 25 75% 45%
- Off-black: 220 10% 8%

### Typography
- **Primary**: Inter (Google Fonts) - clean, professional
- **Accent**: Roboto Condensed for headings - strong, industrial feel
- Sizes: text-sm to text-4xl, weights: 400, 600, 700

### Layout System
**Spacing**: Consistent use of Tailwind units 4, 8, 12, 16 (p-4, m-8, gap-12, etc.)
**Grid**: 12-column responsive grid with generous whitespace

### Component Library

**Navigation:**
- Sticky header with emergency phone button
- Mobile hamburger menu
- Prominent "CALL NOW" CTA button

**Hero Section:**
- Large background image of tow truck in action
- Overlay with company name and 24/7 emergency number
- Primary CTA: "Get Help Now" button (outline variant with blurred background)

**Service Cards:**
- Icon + title + brief description
- Clean white cards with subtle shadows
- Hover effects with orange accent border

**Contact Elements:**
- Emergency banner across top of all pages
- Phone number prominently displayed
- Contact form with validation states
- Location map integration

**Trust Indicators:**
- Testimonial cards with customer photos
- Certifications and insurance badges
- Years of experience highlight

## Images
**Required Images:**
- **Hero**: Professional tow truck on highway (full-width background)
- **Services**: Various towing scenarios (flatbed, emergency roadside)
- **Team**: Local technicians in uniform
- **Fleet**: Multiple trucks showing company scale

## Key Features
- Mobile-first design (most users call during emergencies)
- Fast loading for stressed users
- Clear service area coverage
- Immediate contact options on every page
- Professional yet approachable tone

## Animations
Minimal animations only:
- Subtle hover states on buttons
- Smooth scroll to contact sections
- Loading states for form submissions
